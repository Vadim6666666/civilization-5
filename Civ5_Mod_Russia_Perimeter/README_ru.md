# «Периметр» для России (Civ V: BNW)

Это каркас модификации, добавляющей России уникальную систему боевой готовности «Периметр».

## Структура
- SQL — определения зданий, проектов, политик и атласов.
- Lua/Perimeter — скриптовая логика готовности, триггеров и реакций.
- Lua/ThirdParty/TableSaverLoader.lua — заглушка для сохранения состояния.
- Text — локализация на русском и английском.
- XML — уведомления.
- Tests — сценарии ручной проверки.

## Сборка
1. Импортировать проект в ModBuddy.
2. Убедиться, что все файлы включены в VFS.
3. Собрать мод.
4. Упаковать содержимое папки в архив Civ5_Mod_Russia_Perimeter.zip.

## Известные ограничения
- Реакции и UI содержат заглушки и требуют дальнейшей реализации.
- Система хранения состояния минимальна и не использует Player:SetProperty.
- Нет реальных арт-ресурсов; используются плейсхолдеры.
